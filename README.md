# 🌐 Personal Portfolio Website

Bu repozitoriya mənim fərdi portfolio vebsaytımın kodlarını ehtiva edir. Vebsayt bir Data / Business Analyst olaraq təhsilimi, təcrübəmi, texniki bacarıqlarımı və reallaşdırdığım layihələri nümayiş etdirmək üçün hazırlanıb.

### 🔗 Canlı Demo: [Vebsayta Bax](https://nazrinosmanova.github.io/Portfolio/)

---

## 🛠️ Texnologiyalar
* **HTML5** & **CSS3** (Responziv və müasir dizayn)
* **JavaScript** (İnteraktiv keçidlər və dinamik elementlər)

## 🗂️ Vebsaytın Strukturu

Vebsayt aşağıdakı əsas və əlavə bölmələrdən ibarətdir:

### 📑 Əsas Bölmələr
* **Haqqımda:** Peşəkar profil və analitika sahəsinə baxış.
* **Karyera:** 
  * **Təhsil:** Akademik göstəricilər və ixtisaslaşma.
  * **Təcrübə:** Keçdiyim təcrübə proqramları və peşəkar fəaliyyət.
* **Şəxsi Layihələr:** Power BI hesabatları, SQL analizləri və data vizuallaşdırma layihələrim.
* **Bacarıqlar:**
  * **Texniki Bacarıqlar:** SQL, Power BI (DAX, Power Query), Data Mining, BPMN və s.
  * **Yumşaq Bacarıqlar (Soft Skills):** Problem həll etmə, analitik düşüncə, komanda işi.

### 📌 Əlavə Bölmələr
* **Sertifikatlar:** Sahə üzrə qazanılmış beynəlxalq və yerli sertifikatlar.
* **Könüllü Təcrübə:** Sosial və akademik könüllülük fəaliyyətləri.
* **Dil Bilikləri:** Sahib olduğum xarici dil səviyyələri.
